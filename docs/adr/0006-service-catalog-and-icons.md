# ADR 0006: 서비스 카탈로그와 아이콘

- 상태: 채택
- 날짜: 2026-11-20

## 배경

구성도는 AWS에서 시작하되 일반 서버·DB·큐·사용자도 필요하다. AWS 공식 아이콘은 배포 조건과 상표 확인 전에는 넣지 않는다.

## 결정

- 서비스 정의는 `adapters/catalog/services.ts`에 있다: `id`, 분류(general/aws), 한·영 이름, 검색어, 글리프, 역할 색. 일반 서비스 42개와 AWS 서비스 35개.
- 글리프는 Lucide(ISC) 아이콘 데이터를 쓴다. 고지는 `THIRD_PARTY_NOTICES.md`에 있다. AWS 항목도 Lucide의 일반 기호를 쓰고 서비스 이름은 글자로만 쓴다. 공식 AWS 아이콘이 아니다.
- 타일 색은 역할별(클라이언트, 컴퓨팅, 데이터, 스토리지, 네트워크, 통합, 보안, 운영, 분석, 외부)로 정한다.
- 검색은 두 언어의 이름, ID, 검색어를 대소문자 없이 찾고, ID·검색어 일치 → 이름 시작 → 단어 시작 → 포함 순으로 정렬한다.
- engine은 카탈로그를 모르고 `Appearance` 인터페이스(서비스 모양, 대체 모양, 영역 글리프)만 받는다.

## 결과

`tests/unit/adapters/export.test.ts`가 ID 중복 없음과 한국어·영어 검색을 검사한다. 공식 AWS 아이콘 팩, 사용자 아이콘 업로드, Kubernetes 전용 묶음은 후속 검토다.
