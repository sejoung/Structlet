# ADR 0015: 편집기 화면 구성

- 상태: 채택
- 날짜: 2026-11-20

## 배경

기능이 늘면서 위 막대에 같은 무게의 글자 버튼 15개가 한 줄로 놓였다. 서비스 목록 180여 개 아래에 영역·주석이 묻혔고, 속성 패널은 폼을 쌓기만 했다. 기능은 있어도 정돈된 제품처럼 보이지 않았다.

## 결정

- **위 막대(48px)는 세 구역이다.**
  - 왼쪽(문서): 파일 메뉴(새로 만들기·열기·가져오기·저장·다른 이름으로·샘플), 제목, 제목 바로 뒤의 저장 상태
  - 가운데(편집): 실행 취소·다시 실행, 2D/아이소메트릭 전환
  - 오른쪽: 패널 토글 | 보기 모드·단축키·설정 메뉴(아이콘 팩·테마·언어) | 강조색 **내보내기** 메뉴(SVG/PNG)
  - **저장 상태는 한 곳이다.** 제목 입력칸은 글자 길이만큼 넓어지고(숨긴 사본이 폭을 정한다), 그 바로 뒤에 저장 위치를 보여준다. Drive 파일과 연결되기 전에는 `이 브라우저` 표시와 작은 `Drive 연결` 단추, 연결된 뒤에는 Drive 상태 하나만 둔다. 브라우저 저장과 Drive 상태를 막대 양 끝에 나눠 두었을 때는 어느 쪽이 지금 저장 위치인지 읽기 어려웠다.
  - Drive 상태 아이콘은 일반 구름 기호(Lucide `Cloud*`)다. Google 로고는 원본 그대로 써야 하므로 단색 선으로 바꿔 그린 로고는 쓰지 않는다.
  - 1100px보다 좁으면 저장 상태는 아이콘만 남기고 글자는 툴팁과 화면 낭독기로 전한다.
  - 자주 쓰는 것은 아이콘으로 바로 두고, 가끔 쓰는 것은 메뉴에 넣는다. 메뉴는 키보드로 열고 화살표로 고르며 Esc로 닫는다.
- **왼쪽은 아이콘 레일 + 패널이다.**
  - **서비스**: 검색, 제공자 칩, 최근 사용, 역할별 3열 격자
  - **영역**: 종류마다 테두리 색 견본과 설명
  - **주석**
  - **레이어**: 명시적 계층을 트리로 보여준다. 들여쓰기 선과 영역 이름이 각 영역의 색을 따라, 캔버스에서 보이는 중첩과 같은 색으로 읽힌다. 화면에서 강조하는 곳은 이 한 곳이다. 선택은 캔버스와 같이 움직이고, 이름 바꾸기, 끌어서 부모 바꾸기(한 번의 undo), 접기, 화살표 키 탐색을 지원한다.
- **오른쪽은 인스펙터(288px)다.**
  - 머리글: 객체 아이콘·이름·종류, 복제·고정·삭제 아이콘 버튼
  - 본문: 접는 구역(기본·모양·배치·끝과 경로·위치·크기). 줄마다 "라벨 76px | 입력"으로 맞춘다.
  - 선택지가 적은 값(모양, 크기, 화살표, 선 모양)은 세그먼트, 켜고 끄는 값은 스위치로 둔다.
  - 아무것도 선택하지 않으면 문서 요약과 점검을 보여준다.
- **패널 숨기기**: 위 막대 오른쪽에 **왼쪽 패널 / 오른쪽 패널** 토글 두 개를 고정된 묶음으로 둔다(VS Code의 레이아웃 토글과 같은 방식). 처음에는 `양쪽` 버튼도 있었지만 아이콘(⤢)이 전체 화면이나 보기 모드처럼 읽혀 없앴고, 양쪽은 `⌘\`와 툴팁으로 안내한다.
  - 버튼은 상태와 관계없이 늘 같은 자리에 있고, 패널이 보이면 눌린 상태로 표시된다.
  - 패널 버튼을 레일 아래·인스펙터 머리글·위 막대에 흩어 두면 숨길 때마다 버튼이 나타나고 사라져 위치가 바뀌었다. 그래서 이 한 곳으로 모았다.
  - `⌘\`는 양쪽을 한 번에 토글한다. 레일에서 열린 탭을 다시 누르면 왼쪽 패널이 접힌다(버튼이 아니라 탭의 동작).
  - 상태는 브라우저에 기억하고(`structlet:panels`), 창이 1100px보다 좁아지면 오른쪽 패널을 접는다.
  - 작업 영역은 flex라서 숨긴 패널의 자리를 캔버스가 쓴다. 캔버스 크기가 바뀌면 화면 중심을 유지하도록 이동량을 보정한다.
- **도구**: 캔버스 왼쪽 위 떠 있는 막대.
  - **선택**(V): 기존 동작
  - **손**(H): 모든 끌기가 화면 이동이다. 손잡이·호버·더블클릭 편집이 없다.
  - **연결**(C): 아무 상자에서나 끌어 다른 상자에 놓으면 연결된다. 도구가 유지되어 연달아 그릴 수 있고, 빈 곳 끌기는 화면 이동, Esc는 선택 도구로 돌아간다.
  - Space 임시 손은 모든 도구에서 유지한다. 아이소메트릭 보기는 항상 손이다.
- **보기 모드**(`⌘.`): 패널·도구 막대·편집 손잡이를 숨기고 손 도구로 바꾼 뒤 화면에 맞춘다. 선택은 비운다. 위 막대 가운데는 "보기 모드 끝내기" 하나만 남고, Esc로도 나온다.
- **캔버스 위에 떠 있는 것**: 확대 막대(− 비율 + 화면 맞춤)와 미니맵을 오른쪽 아래에, 알림은 아래 가운데 토스트로 둔다. 하단 상태 표시줄은 없앴고, 도움말은 단축키 창으로 옮겼다.
- **시각 규칙**
  - 색: 회색 계열에 강조색 하나(cyanotype blue `#2F55D4`, 다크 `#7D9BFF`)
  - 크기: 8px 간격, 컨트롤 높이 30px
  - 글자: 섹션 제목은 대문자 라벨 대신 문장형 굵은 글씨. 한국어는 띄어쓰기에서만 줄을 바꾼다.
  - 그림자는 떠 있는 요소(메뉴·확대 막대·미니맵·토스트·대화상자)에만 쓴다.
  - 캔버스 포커스 테두리는 키보드로 들어왔을 때만 보인다.
- 화면 아이콘은 Lucide 데이터(`components/ui/Icon.tsx`)다. 그래서 components 계층에 `lucide` 패키지를 허용한다([ADR 0001](0001-layered-local-first.md)).

## 결과

기능 로직(domain·application·engine·adapters)은 바뀌지 않았다. `tests/e2e/layout-ui.spec.ts`는 레이어 트리, 최근 사용, 단축키 창, 메뉴 키보드 조작을 검사한다. `tests/e2e/tools-panels.spec.ts`는 다음을 검사한다.

- 패널 토글: 접기·기억·`⌘\`, 위 막대 버튼 위치 고정, 저장 상태가 제목 바로 뒤에 붙고 제목 길이를 따라감
- 손 도구: 화면만 이동, 문서 불변, 선택·편집 없음
- 연결 도구: 두 번 연속 연결, 빈 곳 이동, Esc
- 보기 모드 다른 e2e는 메뉴를 거치는 `act()` 도우미로 바꿨다.
