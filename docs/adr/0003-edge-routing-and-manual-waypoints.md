# ADR 0003: 연결선 — 직교 자동 경로와 수동 꺾임점

- 상태: 채택
- 날짜: 2026-11-20

## 배경

Stormlet 연결선에는 수동 꺾임점이 없고, 장애물 회피에 탐색 상한이 있었다([참고](stormlet-reference/0019-diagram-polish.md)). 구성도 편집기는 자동 경로로 시작하되 사용자가 경로를 고칠 수 있어야 하고, 노드를 옮긴 뒤에도 그 의도가 남아야 한다.

## 결정

- **끝점(`Endpoint`).** 노드·영역에 붙은 끝(`objectId`, `side`: auto/top/right/bottom/left, `offset`: 0..1 또는 null)과 월드 좌표의 자유 끝점(`free`) 두 종류다. 노드의 아래 면은 이름 아래에 있어 선이 글자를 지나지 않는다.
- **면 고르기와 포트 분산.** `auto` 면은 상대 끝(수동 경로면 가장 가까운 꺾임점)을 향한다. `offset`이 없는 끝들이 한 면을 쓰면 상대 위치 순서대로 최대 16px 간격, 면 길이 80% 안에서 벌린다.
- **자동 경로(`auto`).** 포트에서 20px 나간 지점 사이를 기본 L/Z 모양으로 잇고, 다른 노드 타일·이름(12px 여유)과 겹치거나 되돌아가면 A*로 다시 찾는다. 격자는 장애물 가장자리와 끝점 좌표로 만든 희소 격자이고, 비용은 길이 + 꺾임당 40이다. 탐색 범위는 끝점 상자 + 240px, 장애물 60개 초과나 경로 없음이면 기본 모양을 쓴다. 영역은 장애물이 아니다. 자동 경로는 저장하지 않고 장면 계산 때마다 만든다(입력이 같으면 캐시).
- **수동 경로(`manual`).** 사용자가 고친 경로는 꺾임점(`waypoints`, 월드 좌표)으로 저장한다. 경로는 시작 포트 → 꺾임점들 → 끝 포트를 직교로 잇고, 정렬되지 않은 구간에는 꺾임 하나를 넣는다. 끝 노드를 옮겨도 꺾임점은 그대로 지나므로 편집 의도가 남는다. 양 끝이 모두 함께 움직이면(영역 이동 등) 꺾임점도 같이 옮긴다.
- **편집.** 선택한 선의 선분 손잡이(또는 선 자체)를 끌면 선분이 수직 방향으로 평행 이동한다(8px 격자). 끝점에 닿은 선분은 20px 짧은 꼬리를 남겨 포트에서 곧게 나가게 한다. 처음 편집할 때 현재 자동 경로의 꺾임점을 그대로 넘겨받으므로 모양이 튀지 않는다. 직선 모양 선은 선분 손잡이로 꺾임점을 넣고, 꺾임점을 끌어 옮기고, 더블클릭으로 지운다. 끝점 손잡이를 다른 객체로 끌면 다시 붙는다(면 근처면 그 면과 위치 고정, 안쪽이면 auto, 빈 곳이면 자유 끝점). "경로 초기화"는 자동 경로로 돌린다.
- **스타일.** 라벨, 점선, 화살표(end/start/both/none), 모양(orthogonal/straight).
- **붐비는 면 피하기.** `auto` 면 바로 앞(32px)에 다른 노드(상대 끝 제외)가 있으면 다음 순서로 고른다: 상대 쪽으로 꺾이는 면 → 반대 직각 면 → 뒷면.
- **교차·겹침 줄이기.** 선은 문서 순서대로 경로를 정한다. 앞서 그린 선과 겹치는 기본 모양은 버리고 A*로 다시 찾는다. A*는 앞선 선과의 교차마다 28, 같은 선 위를 달리는 길이 1px마다 1.5를 더 친다. 앞선 선 양옆 12px에 차선을 더해 평행선이 떨어져 지나게 한다.
- **수동 경로의 장애물.** 사용자가 둔 꺾임점은 그대로 지난다. 꺾임점 사이 연결 구간이 노드에 걸리면 그 구간만 돌아간다.
- **라벨 자리.** 선 라벨은 경로 가운데에 두되, 노드나 앞선 라벨과 겹치면 경로의 40·60·30·70·20·80% 지점 중 처음 비는 곳에 둔다.

## 결과

`tests/unit/engine/routing.test.ts`가 기본 모양 유지, 장애물 우회, 편집한 경로의 재현과 끝점 이동 후 꺾임점 유지, 포트 분산·고정 위치를, `scene.test.ts`가 샘플의 모든 선이 다른 노드를 지나지 않음을 검사한다. e2e는 선분 끌기 → 노드 이동 후 꺾임점 유지 → undo → 초기화와 끝점 재부착을 확인한다.

`tests/unit/engine/quality.test.ts`가 붐비는 면 피하기, 수동 경로 구간 우회, 라벨 겹침 회피, 대형 문서 성능을 검사한다. 노드 400개·선 300개의 첫 계산은 약 0.2초다(개발 장비 기준; 테스트 상한 4초). 끌기 중에는 영향받지 않은 선의 경로 캐시를 쓴다.

여러 선을 한 줄기로 합치는 **선 묶기는 하지 않는다**. 포트 분산과 차선 분리로 선마다 출발·도착점을 구분하는 방식을 택했기 때문이다. 전역 최적 교차 최소화도 하지 않는다(순차 경로 + 비용).
