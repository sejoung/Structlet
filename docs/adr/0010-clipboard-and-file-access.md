# ADR 0010: 클립보드와 같은 파일에 저장

- 상태: 채택
- 날짜: 2026-11-20

## 결정

- **클립보드.** 복사·잘라내기·붙여넣기는 브라우저의 `copy`/`cut`/`paste` 이벤트로 처리해 권한 요청이 없다.
  - 클립보드에는 선택을 담은 작은 `.structlet` 문서(`extractFragment`)를 넣는다. 루트 상자는 월드 좌표로, 내용은 로컬 좌표로 담고, 내부 선과 수동 꺾임점도 함께 담는다.
  - 붙여넣을 때 파일과 같은 검증을 거친다. 새 ID로 바꾸고, 선택한 영역(없으면 화면 가운데 아래 영역)에 24px씩 비켜 넣는다.
  - 구성도 조각이 아닌 텍스트(초안 JSON, compose, Terraform JSON)를 붙여넣으면 가져오기로 처리한다.
- **같은 파일에 저장.** `LocalFileAccess`(adapters)는 다음처럼 동작한다.
  - File System Access API가 있으면 **열기**로 받은 파일에 **저장**이 바로 쓴다. **다른 이름으로**는 저장 위치를 묻고 그 파일을 이후 저장 대상으로 삼는다.
  - API가 없거나 자동화 브라우저(`navigator.webdriver`)에서는 파일 입력과 다운로드로 대신한다.
  - 새로 만들기·샘플 열기는 저장 대상을 잊는다. 가져오기는 저장 대상을 바꾸지 않는다.

## 결과

`tests/unit/domain/fragment.test.ts`가 영역 복사·직렬화·붙여넣기(새 ID, 부모, 월드 위치, 내부 선)를 검사한다. `tests/unit/adapters/services.test.ts`는 핸들에 다시 쓰기와 대체 경로를 검사한다. e2e는 영역 복사·붙여넣기와 undo를 확인한다.
