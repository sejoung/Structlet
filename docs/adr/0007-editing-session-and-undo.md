# ADR 0007: 편집 세션, 미리보기, 실행 취소

- 상태: 채택
- 날짜: 2026-11-20

## 배경

끌기 중의 화면 갱신과 기록되는 변경을 분리해야 "영역 이동은 한 번의 undo"가 성립한다. 문서와 선택·호버·뷰포트 같은 편집 상태도 분리한다.

## 결정

- domain 명령은 순수 함수로 문서를 읽고 `Patch`(객체별 before/after, 삭제·삽입 위치)를 돌려준다. 패치는 뒤집을 수 있고(`invertPatch`), 이어 붙이면 같은 객체의 변경이 합쳐진다(`composePatches`).
- `EditorSession`(application)은 확정 문서, 미리보기 패치, undo/redo 스택(최대 200), 선택, 변경 번호를 가진다. React 없이 구독(`useSyncExternalStore`)할 수 있다.
- 끌기·크기 조절·선 편집은 진행 중에 `preview`만 바꾸고, 놓을 때 한 번 `execute`한다. 놓기 전 문서는 바뀌지 않는다.
- 같은 `coalesceKey`의 연속 변경(이름 입력, 제목, 키보드 이동)은 1.2초 안이면 한 undo 단계로 합친다.
- undo/redo는 그 단계 전후의 선택을 되살린다. 새 변경은 redo를 지운다. 파일 열기·새로 만들기는 기록을 비운다.
- `Editor`(application)는 노드 추가, 영역 추가·감싸기, 연결, 이동, 정렬 적용, 경로 설정 같은 유스케이스를 한 단계씩 제공한다. 놓을 위치의 부모나 정렬량처럼 기하 판단은 engine을 쓰는 화면 쪽이 계산해 넘긴다.
- 뷰포트, 호버, 진행 중 제스처, 인라인 편집 대상은 문서에 저장하지 않는다.

## 결과

`tests/unit/application/session.test.ts`가 노드 두 개 연결, 미리보기 후 한 번의 커밋과 undo/redo, 입력 합치기, 선택 복원, 잘못된 명령 무시, 수동 경로 저장·초기화를 검사한다.

클립보드 복사·붙여넣기, 실시간 협업용 병합은 다루지 않는다.
