# ADR 0005: 캔버스와 내보내기가 같은 렌더러를 쓴다

- 상태: 채택
- 날짜: 2026-11-20

## 배경

내보낸 SVG·PNG는 화면과 같은 아이콘·라벨·경로여야 한다. 화면용 React 렌더러와 내보내기용 렌더러를 따로 두면 조금씩 어긋난다.

## 결정

- engine의 `computeScene(document, appearance)`가 월드 좌표의 장면(영역 깊이 순서, 노드 타일·이름 줄, 연결선 경로·라벨 상자, 주석, 포트 틀, 경계)을 계산한다.
- engine의 `renderSceneBody(scene)`가 장면을 SVG 마크업 문자열로 만든다. DOM을 쓰지 않는 순수 함수다.
- 캔버스는 이 마크업을 그대로 변환(`translate·scale`) 그룹 안에 넣고, 그 위에 투명한 히트 영역과 선택·손잡이 레이어를 따로 그린다.
- SVG 내보내기는 같은 마크업을 경계 + 32px 여백으로 자른 `<svg>`로 감싼다. PNG는 그 SVG를 2배 크기 캔버스에 그린다.
- 글자 폭은 문자 종류별 추정치로 계산해 DOM 측정에 기대지 않는다. 줄바꿈은 띄어쓰기 단위(한국어 단어 유지)이고, 한 줄보다 긴 단어만 글자 단위로 자른다. 줄은 `tspan`으로 확정되어 화면과 파일이 같다.

## 결과

`tests/unit/adapters/export.test.ts`가 내보낸 SVG에 캔버스 마크업과 모든 경로·라벨이 들어 있음을, e2e가 화면 경로의 `d`와 내보낸 SVG의 `d`가 같음과 PNG 생성을 확인한다.

글꼴은 시스템 글꼴 스택을 이름으로만 지정하고 파일에 넣지 않는다. 다른 컴퓨터에서 SVG를 열면 글자 폭이 조금 다를 수 있다(가운데 정렬이라 배치는 유지된다).
