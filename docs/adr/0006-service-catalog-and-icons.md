# ADR 0006: 서비스 카탈로그와 아이콘

- 상태: 채택 (2026-11-20 개정: 제공자별 카탈로그, 아이콘 팩은 [ADR 0013](0013-icon-packs.md))
- 날짜: 2026-11-20

## 배경

구성도는 AWS에서 시작하되 일반 서버·DB·큐·사용자와 다른 클라우드도 필요하다. 제공자 공식 아이콘을 앱에 넣어 배포하는 것은 별도 허가가 필요할 수 있다.

## 결정

- **서비스 정의와 모양을 나눈다.** 서비스 정의(카탈로그)는 무엇인지를, 아이콘 팩은 어떻게 보이는지를 맡는다. 문서는 서비스 ID만 저장한다.
- **카탈로그**(`adapters/catalog/`)는 제공자별 파일로 나눈다. 항목마다 `id`, 제공자, 한·영 이름, 검색어, 일반 기호, 역할 색을 가진다.

  | 파일 | 제공자 | 항목 수 | ID 형식 |
  | --- | --- | --- | --- |
  | `general.ts` | 일반 | 42 | `database` |
  | `aws.ts` | AWS | 35 | `aws.ec2` |
  | `gcp.ts` | Google Cloud | 35 | `gcp.cloud-run` |
  | `azure.ts` | Azure | 34 | `azure.aks` |
  | `k8s.ts` | Kubernetes | 14 | `k8s.deployment` |
- **일반 기호**는 Lucide(ISC) 아이콘 데이터다(`THIRD_PARTY_NOTICES.md`). 제공자 서비스도 일반 기호로 그리고 서비스 이름은 글자로만 쓴다. 공식 아이콘은 사용자가 불러온 아이콘 팩에서만 온다.
- **타일 색**은 역할별(클라이언트, 컴퓨팅, 데이터, 스토리지, 네트워크, 통합, 보안, 운영, 분석, 외부)이다.
- **검색**은 두 언어의 이름, ID, 검색어를 찾고, 다음 순서로 정렬한다: ID·검색어 일치 → 이름 시작 → 단어 시작 → 포함. 팔레트는 제공자별로 접히는 묶음이다.
- **engine은 카탈로그를 모른다.** `Appearance`만 받는다. `Appearance`는 서비스 모양(이름, 기호, 색, 선택적 이미지), 대체 모양, 영역 기호·이미지를 돌려준다.
- **영역 종류**는 cloud, account, region, availability-zone, vpc, subnet, cluster, namespace, custom이다.

## 결과

`tests/unit/adapters/export.test.ts`가 ID 중복 없음과 한국어·영어 검색을 검사한다. 상표 고지는 아이콘 팩 창과 README에 있다.
