# ADR 0011: 보기, 테마, 접근성

- 상태: 채택
- 날짜: 2026-11-20

## 결정

- **테마.** 시스템·라이트·다크를 고른다. 화면 틀은 CSS 토큰(`html[data-theme]`)으로, 구성도는 렌더러의 `DiagramTheme`(선·글자·배경·범례 색)으로 바꾼다. 영역과 서비스 색은 두 테마에서 같다. 내보내기는 문서용으로 항상 라이트 테마를 쓴다.
- **노드 모양.** `Node.variant`: `icon`(타일 + 아래 이름, 기본)과 `box`(테두리 상자 안에 아이콘과 이름). 크기 프리셋은 S/M/L이다. 이 필드가 없는 v1 파일은 `icon`으로 읽는다.
- **범례.** 범례 주석의 줄은 `#rrggbb`(색 견본)·`---`(실선)·`- -`(점선)으로 시작할 수 있다. 범례를 추가하거나 "다시 만들기"를 누르면 문서에서 쓰는 역할 색과 선 모양으로 범례를 채운다.
- **주석 대상.** 주석을 객체에 붙이면(`targetId`) 대상 옆으로 옮겨지고, 이후 대상과 함께 움직인다.
- **아이소메트릭 보기.** 같은 장면을 투영해 그리는 읽기 전용 보기다. 영역·선·서비스 아이콘은 바닥면에 눕고, 서비스는 블록으로 서고, 글자는 똑바로 선다. 이 보기에서 SVG·PNG를 내보내면 아이소메트릭 그림이 나온다. 편집은 2D에서만 한다.
- **미니맵.** 전체와 보이는 범위를 보여주고, 누르거나 끌어 이동한다.
- **터치.** 한 손가락으로 빈 곳을 끌면 이동하고, 두 손가락으로 확대한다. 거친 포인터에서는 손잡이를 키운다.
- **키보드.** 캔버스에 포커스가 가고, Tab/Shift+Tab으로 객체 사이를 옮긴다(화면 밖이면 따라간다). 선택은 `aria-live`로 읽어 준다. 나머지 편집은 기존 단축키와 속성 패널로 한다.

## 결과

`tests/unit/engine/quality.test.ts`가 상자 노드의 포트와 렌더링, 범례 견본, 다크 테마 색, 아이소메트릭 출력을 검사한다. e2e는 테마 전환, 상자 모양, 범례 생성, 미니맵 이동, Tab 이동과 읽어 주기, 아이소메트릭 보기와 내보내기, 터치 이동·확대를 확인한다.
